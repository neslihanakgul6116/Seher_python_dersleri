# 🛒 E-Ticaret & Sepet Yönetimi API'si

FastAPI ve Pydantic kullanılarak geliştirilmiş, ürün kataloğu yönetimi ve sepet işlemlerini sağlayan RESTful bir API projesidir.

## 🚀 Özellikler

* 📦 **Ürün Kataloğu:** Tüm ürünleri listeleme ve yeni ürün ekleme.
* 🛒 **Sepet Yönetimi:** Sepete ürün ekleme ve toplam sepet tutarını hesaplama.
* 📑 **Otomatik Dokümantasyon:** Swagger UI ve ReDoc desteği.

## 🛠️ Teknolojiler

* **Python 3.10+**
* **FastAPI**
* **Uvicorn**
* **Pydantic**
